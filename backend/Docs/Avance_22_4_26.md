## Comandos para lavantar el proyecto

Para levantar el proyecto se debe:

### Para levantar el backend

1. Ir a la carpeta backend con el comando cd backend
2. Iniciar el entorno virtual con el comando: source venv/Scripts/activate
3. Iniciar el servidor con el comando: python manage.py runserver

### Para levantar el frontend

1. Ir a la carpeta frontend con el comando: cd frontend
2. Iniciar el servidor con el comando: npm run dev
